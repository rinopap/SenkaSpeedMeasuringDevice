# Phase 5 ローカルプロキシ試験

これは **ローカルテスト専用** の試験ハーネスです。Titanium.Web.Proxy 3.2.0を使い、A/B/Cの経路をローカルの模擬プロキシで再現します。製品アプリの通信機能ではありません。

## 試験内容

- `127.0.0.1` 上で自己署名TLSサーバーを起動します。
- 試験専用CA/証明書をプロセス内で作り、Windows証明書ストアやブラウザへ登録しません。
- システムプロキシ設定を読んだり変更したりしないよう、Titaniumを `Start(false)` で起動します。
- 次のリクエスト方向をそれぞれ1回試します。
  - A: クライアント → 捕捉プロキシ → テストサーバー
  - B: クライアント → 74EN相当の模擬プロキシ → 捕捉プロキシ → テストサーバー
  - C: クライアント → 捕捉プロキシ → 74EN相当の模擬プロキシ → テストサーバー
- メソッド、Host、URIとクエリ、API風リクエスト本文、オリジン応答/クライアント応答/解析用コピーの本文が一致するかを検査します。
- 接続先はランダムポートのloopbackだけです。実ゲーム、実74EN、外部サーバーには接続しません。

B/Cの模擬プロキシはTitanium.Web.Proxy 3.2.0で作っています。実74ENとの併用試験の結果ではありません。

## 実行

Windowsで.NET SDK 8.0を使い、次を実行します。

```powershell
dotnet run --project Phase5LocalProxyProbe.csproj
```

試験はローカルNuGetキャッシュのTitanium.Web.Proxy 3.2.0で実行しました。SDKがパッケージを取得できる必要があります。2026-11-26時点で.NET 8のサポートは終了しているため、これは再現用ハーネスのターゲットに限ります。製品用サイドカーを作る場合は、サポート中の.NET 10 LTSを使い、Titanium.Web.Proxyの更新版へ移行した回帰試験を別途実施してください。

## 制約

HTTP/1.1の小さな非圧縮レスポンスのみです。実ゲーム証明書、実74EN設定、HTTP/2/3、圧縮/大容量データ、性能、障害/終了復旧は検証しません。TLSセッションはプロキシで終端するため、TLSレコードや証明書そのものが端点間で同じという試験ではありません。
