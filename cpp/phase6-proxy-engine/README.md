# Phase 6 検証用プロキシエンジン

Titanium.Web.Proxy 8.0.2を用いた、併用確認用の独立プロセスです。Qtアプリ本体とのIPC統合や設定UIは未実装です。A/B/Cのプロキシ接続をローカルテスト環境で確認するために使います。74ENは3.2.0を参照しているため、バージョン差の実機互換性は別途確認が必要です。

## 安全境界

- `127.0.0.1` にだけ待ち受けます。Windows証明書ストア、システムプロキシ、ブラウザー設定を読み書きしません。
- サーバー証明書検証を無効にするコードはありません。上流プロキシ/TLS検証はTitaniumの既定検証に任せます。
- リクエスト本文を取得しません。要求や応答を保存・送信・変更する処理、ゲームAPIの追加送信や再送はありません。
- Titaniumの通信失敗時リトライを0回にし、`Via`ヘッダー追加も無効化します。通信に失敗した要求はそのまま失敗として返り、再送しません。
- `/kcsapi/api_port/port` の成功応答だけを一時メモリで解析し、経験値数値と時刻だけを標準出力に出します。本文やCookie、URLクエリは出力しません。
- 現行プロトコル設定はHTTP/2を無効にしたHTTP/1.1です。Titanium.Web.Proxy 8.0.2でHTTP/2有効時にローカルHTTPS試験が停止したため、HTTP/2対応が確認できるまで実機へ接続しません。
- Qtアプリから起動すると、ユーザー別アプリデータにCA秘密鍵を保持し、選択した場所へ公開CA証明書だけを書き出します。証明書の信頼登録・システムプロキシ設定は行いません。
- CA証明書の出力は `--export-ca` を明示したときだけ行います。出力するのは公開証明書です。証明書ストアへの登録は行いません。
- 現段階ではローカルテスト用です。実ゲーム通信を流さないでください。Qtアプリとの統合前なので、出力値はUIへ届きません。

## ビルド・起動

.NET 10 LTS SDKが必要です。

```powershell
dotnet build Phase6ProxyEngine.csproj -c Release
dotnet run --project Phase6ProxyEngine.csproj -- --listen-port 8877 --export-ca .\test-proxy-root.cer
```

上流プロキシを経由する構成Cの形を試す場合:

```powershell
dotnet run --project Phase6ProxyEngine.csproj -- --listen-port 8877 --upstream-port 8888 --export-ca .\test-proxy-root.cer
```

上流ポートは指定したときのみloopback `127.0.0.1` へ接続します。Ctrl+Cで停止します。

## 重要

証明書は毎回メモリ上で新規生成されます。上記 `--export-ca` は証明書をファイルに書くだけで、信頼ストアに登録しません。ユーザーの明示操作なしに登録してはいけません。実74EN/実ゲーム試験へ進む前に、別途説明と明示同意が必要です。現行Qtアプリにこのエンジンを接続しないでください。
