# 戦果時速計測機 C#移行版（検証用）

本ZIPはWindows x64向けの.NET self-contained Release候補です。.NETの事前インストールは不要です。

## 起動

1. ZIPを展開します。
2. 書込み可能なフォルダへ置きます。CSV、設定、74EN JSON監視フォルダをアプリ実行フォルダの下に作るため、`Program Files`配下は避けてください。
3. `SenkaSpeedMeasuringDevice.App.exe`を起動します。

保存先:

- `exp_log.csv`
- `ship_exp_log.csv`
- `ui_config.json`
- `74en_responses/`

## 74EN JSONモード

既定は「74EN JSON監視」です。タブ列にある監視状況へマウスを合わせると、`74en_responses`のフルパスを確認できます。これを74ENの通信内容保存設定でresponseの保存先に指定してください。`api_port@port*.json`を監視します。

## 通常ブラウザCDPモード

CDPを使う場合は専用のゲーム用プロファイルを使い、Chrome/Edgeのremote debuggingをloopback (`127.0.0.1`) に限定してください。通常利用中のブラウザプロファイルを使わないでください。この設定は強いローカル制御面を開くため、設定画面からCDPを明示的に有効にした場合だけ接続を試みます。本アプリはブラウザ設定を変更しません。

設定画面では以下を選択・入力します。

- 所属サーバー（20サーバーから選択）
- CDPポート

ゲームページURL、APIパス、APIホストは固定され、任意の値を入力できません。選択したサーバーのHTTPSホストにある`/kcsapi/api_port/port`の成功レスポンス本文だけを読み取ります。Cookieやリクエスト本文を取得せず、ページへのコード注入やゲームAPI送信をしません。

メイン画面では、監視方式の短い状態をタブ列に表示します。マウスを合わせると監視先や詳細状態をツールチップで確認できます。設定は歯車アイコンから開きます。

## 既知の検証範囲

- この配布候補はM10時点のものです。M11で設定画面とCDP制約が更新されているため、M11ソース確認には使用しないでください。
- M10時点のxUnitは20件成功。通常Edgeのloopback合成HTTP本文ハッシュ一致、取得プロセス終了後も合成ブラウザ通信が継続することを確認済み。
- 利用者から、実ゲームでの通常ブラウザCDP、74EN JSON監視、74EN WebView2 CDP、CSVコピーの読込/追記、計測機終了後もゲーム通信が継続することを確認したとの報告があります。ウィンドウ取り込み、DPI、実ログオン後の自動起動、長時間動作は未確認です。このZIPは検証用候補であり、正式公開版ではありません。
