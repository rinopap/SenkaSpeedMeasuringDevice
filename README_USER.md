# 戦果時速計測機 C#移行版（検証用）

本ZIPはWindows x64向けの.NET self-contained Release候補です。.NETの事前インストールは不要です。

## 起動

1. ZIPを展開します。
2. 書込み可能なフォルダへ置きます。CSV、設定、74EN JSON監視フォルダをアプリ実行フォルダの下に作るため、`Program Files`配下は避けてください。
3. `SenkaSpeedMeasuringDevice.App.exe`を起動します。

保存先:

- `exp_log.csv`
- `ship_exp_log.csv`
- `ui_config.json`
- `74en_responses/`

## 74EN JSONモード

既定は「74EN JSON監視」です。タブ列にある監視状況へマウスを合わせると、`74en_responses`のフルパスを確認できます。これを74ENの通信内容保存設定でresponseの保存先に指定してください。`api_port@port*.json`を監視します。

## 通常ブラウザCDPモード

CDPを使う場合は、設定画面の「ログイン準備」と「計測開始」を別々に実行してください。

1. 対応ブラウザと所属サーバーを選び、「ログイン準備」を押します。専用プロファイルをCDPなしで開き、認証はブラウザ上で利用者自身が行います。
2. 認証後、専用ブラウザを利用者自身で閉じます。アプリはブラウザを終了したり再起動したりしません。
3. 「計測開始」を押すと、同じ専用プロファイルでブラウザをloopback (`127.0.0.1`) 限定のCDP付きで起動し、明示操作によって計測を開始します。母港APIを受け取るまでは計測中と表示しません。

専用プロファイルは通常利用中のブラウザプロファイルと別です。ログイン状態はブラウザ自身が管理し、Cookie、パスワード、APIトークンの読み取りや他プロファイルからの移送は行いません。CDPはブラウザの内容を扱える強い権限を持ちます。計測機を終了しても、ブラウザを閉じるまでデバッグ待受は残ることがあります。

既にCDPが有効なブラウザを利用する場合は、接続先を詳細情報で設定した後、利用者が「計測開始」を明示してください。74ENは起動・終了せず、既存のJSON監視方式も利用できます。

- 所属サーバー（20サーバーから選択）
- CDPポート（ブラウザ起動補助では自動設定）

ゲームページURL、APIパス、APIホストは固定され、任意の値を入力できません。選択したサーバーのHTTPSホストにある`/kcsapi/api_port/port`の成功レスポンス本文だけを読み取ります。認証ページの本文は取得せず、Cookieやリクエスト本文も取得しません。ページへのコード注入やゲームAPI送信をしません。

Chrome 144以降の承認型CDPはChrome DevTools MCP向けに公式案内されていますが、本アプリのC#クライアントから接続できる公式インターフェースは確認できていないため、現時点では採用していません。CDPの利用が技術的に可能であることは、ゲーム運営または認証サービスの許可を意味しません。

メイン画面では、監視方式の短い状態をタブ列に表示します。マウスを合わせると監視先や詳細状態をツールチップで確認できます。設定は歯車アイコンから開きます。

## 既知の検証範囲

- この配布候補はM10時点のものです。M11で設定画面とCDP制約が更新されているため、M11ソース確認には使用しないでください。
- M10時点のxUnitは20件成功。通常Edgeのloopback合成HTTP本文ハッシュ一致、取得プロセス終了後も合成ブラウザ通信が継続することを確認済み。
- 利用者から、実ゲームでの通常ブラウザCDP、74EN JSON監視、74EN WebView2 CDP、CSVコピーの読込/追記、計測機終了後もゲーム通信が継続することを確認したとの報告があります。ウィンドウ取り込み、DPI、実ログオン後の自動起動、長時間動作は未確認です。このZIPは検証用候補であり、正式公開版ではありません。
