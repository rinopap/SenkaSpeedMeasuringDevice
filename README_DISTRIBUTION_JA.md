# 戦果時速計測機

**SenkaSpeedMeasuringDevice v2.0.0** は、ElectronicObserverEN（74EN）が標準保存したデータから戦果時速と艦娘Exp時速を計測するWindows向けの非公式補助ツールです。

艦これ運営および74ENとは別に開発・配布するツールです。ゲーム通信を仲介・変更したり、ゲーム操作を自動化したりしません。

## 対応環境

- Windows x64
- ElectronicObserverEN 5.4.3EN
- .NET 10ランタイムは配布ファイルに含まれています。

これ以外の74ENバージョンおよびWindows ARM環境は、この配布版の対応確認範囲外です。

## 使用方法

1. `SenkaSpeedMeasuringDevice-v2.0.0-win-x64.zip`をローカルフォルダへ展開します。
2. `SenkaSpeedMeasuringDevice.App.exe`を起動します。
3. 必要に応じて設定画面から取得方式と74ENの`Record\ElectronicObserver.sqlite`を指定します。
4. SQLite方式を使う場合、74ENの個別JSON保存設定は不要です。

JSON方式は従来の互換方式として利用できます。両方式の同時監視は行いません。

## 計測方式と制約

- **戦果時速**：母港APIで記録された提督累積経験値の差分から算出します。
- **SQLite方式のExp時速**：通常艦隊の戦闘・演習・遠征の結果APIに記録された艦隊獲得Expを集計します。
- **JSON方式のExp時速**：全所持艦の累積経験値差分を使います。

SQLite方式とJSON方式のExp時速は異なる指標で、値が一致するとは限りません。API記録が保存されなかった場合や観測に欠損がある場合は計測できないことがあります。経験値上限等によりAPI獲得値が実際の加算値と異なる場合もあります。連合艦隊は正式対応対象外です。

## 保存データと更新

設定とCSVログは実行ファイルと同じフォルダに保存されます。計測履歴と取得位置は`%LOCALAPPDATA%\SenkaSpeedMeasuringDevice`に保存します。設定・CSVの保存場所を変える場合は、既存データを上書きする前にバックアップしてください。

74ENのSQLiteは読み取り専用で開きます。SQLite標準の共有ロック管理に伴い、`-shm`等の補助ファイル状態が変わることがあります。74EN管理ファイルはこのツールが削除しません。

## セキュリティとプライバシー

本ツールはゲーム通信へ介入せず、認証情報を取得・保存・送信せず、計測機能から外部サービスへ利用者データを送信しない設計です。アプリの起動・終了は74ENの起動・終了を制御しません。

本ツールは未署名です。Windows SmartScreen等の警告が表示される場合があります。警告を避けるためにWindowsやウイルス対策ソフトの保護を無効にしないでください。公開後は配布ページのSHA-256と照合してファイルの一致を確認できますが、SHA-256単独では配布元の真正性は保証されません。
